# Republia Times

[Republia Times](http://dukope.com/#trt) was created by Lucas Pope. The source
code for the game was released on Lucas Pope's website.

This is a port of the original flash game to the standard web languages of
JavaScript, HTML, and CSS.

## A Highlight of Some Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode.

### `npm run test`

Runs all the tests.

### `npm run build`

Builds the app for production to the `dist` folder.
